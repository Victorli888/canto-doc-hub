# Software and Tech Vocabulary

The terms behind [[describing-my-job]]. A list beats prose here, but the column that
matters is the last one: for most of these there is a Chinese word *and* an English word
in live use, and picking the Chinese one when Hong Kong uses the English one is a
textbook tell — the same trap as 加班 for 做OT in [[work-small-talk]].

All readings below were checked against [words.hk](https://words.hk) or
[Wiktionary](https://en.wiktionary.org); the raw source had two of them wrong, see
[[describing-my-job-dump]].

| Chinese | Jyutping | English | What a HK engineer actually says |
|---|---|---|---|
| 軟件 | jyun5 gin6-2 | software | 軟件 — but note the tone, see [[tone-sandhi]] |
| 硬件 | ngaang6 gin6-2 | hardware | 硬件 |
| 工程師 | gung1 cing4 si1 | engineer | 工程師 |
| 程式 | cing4 sik1 | program / code | **code** — 寫code, not 寫程式 |
| 編程 | pin1 cing4 | programming | **coding** / 寫code |
| 開發 | hoi1 faat3 | develop | 開發, or just **develop** |
| 維護 | wai4 wu6 | maintain | 維護, or **maintain** |
| 系統 | hai6 tung2 | system | 系統 / **system** |
| 平台 | ping4 toi4 | platform | 平台 / **platform** |
| 網站 | mong5 zaam6 | website | 網站 / **site** |
| 電子商務 | din6 zi2 soeng1 mou6 | e-commerce | 電子商務 in a deck; **ecom** / 網上商店 in talk |
| 網上商店 | mong5 soeng6 soeng1 dim3 | online store | 網上商店 / **online shop** |
| 客戶 | haak3 wu6 | client, customer | 客戶; 客 (haak3) on its own is the shop-floor word |
| 訂單 | deng6 daan1 | order (noun) | 訂單 — 訂 is **deng6**, not ding6 |
| 落單 | lok6 daan1 | place an order (verb) | 落單 |
| 負責 | fu6 zaak3 | be responsible for | 負責 at work; 搞 (gaau2) with friends |
| 返工 | faan1 gung1 | go to work | 返工, never 工作 or 上班 |
| 公司 | gung1 si1 | company | 公司 |
| 人工智能 | jan4 gung1 zi3 nang4 | artificial intelligence | 人工智能, but usually just **AI** in speech |
| 判斷 | pun3 dyun3 | judge, decide | 判斷 |
| 執行 | zap1 hang4 | execute, carry out | 執行 |
| 改 | goi2 | fix, correct | 改 — ordinary word, not technical |
| 架構 | gaa3 gau3 | architecture (of a system) | 架構 |

## The one pattern to take away

件 is gin6 standing alone, but surfaces as **gin2** in 軟件, 硬件 and 組件. Three words,
one rule. Say jyun5 gin6 and you sound like you read it rather than heard it.
See [[tone-sandhi]].
